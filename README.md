# Emberfall Duel

An original browser card battler: out-duel Morvane the Warden. Both hands are
face-up on the table, his next move is always declared as an intent you can
counter, and chaining same-suit cards earns Suit Surge bonuses. Four suits —
Ember (red ▲), Tide (blue ●), Thorn (green ◆), Void (purple ★) — each with
readable energy cost and power. Play with mouse or keys 1–5, Space ends the
turn, M mutes. Static files only: open `game/index.html` in Chrome.
